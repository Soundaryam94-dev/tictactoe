# TicTacToe

Play Tic Tac Toe directly inside VS Code!

## Features

- 3x3 game board rendered in a VS Code Webview panel
- Two-player turn-based gameplay (X and O)
- Win detection with highlighted winning cells
- Draw detection
- Restart button to reset the game

## How to Use

1. Open the Command Palette (`Ctrl+Shift+P`)
2. Type and run **Play TicTacToe**
3. Click cells on the board to place your mark
4. First player to get 3 in a row wins!
